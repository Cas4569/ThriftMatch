## Deploy on Vercel

### Firebase Admin credentials

Seller applications are written to Firestore by the server. For Vercel, add the
Firebase Admin service-account JSON as the `FIREBASE_SERVICE_ACCOUNT_JSON`
environment variable for the Production environment, then redeploy. Keep this
credential private; do not commit the service-account file or expose the value
through a `NEXT_PUBLIC_` variable.

Alternatively, set `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, and
`FIREBASE_PRIVATE_KEY` as server-only environment variables. The project ID can
also fall back to `NEXT_PUBLIC_FIREBASE_PROJECT_ID`. Redeploy after changing
environment variables.
